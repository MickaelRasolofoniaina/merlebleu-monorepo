# Challenge de compréhension du code Merlebleu

Objectif: garder une compréhension totale du projet même quand le code est écrit par une IA.

## Fichiers

| Fichier | Contenu |
| --- | --- |
| [questions.md](questions.md) | Les 15 questions, classées par niveau. Commencez ici. |
| [corrige.md](corrige.md) | Les réponses attendues. **Ne pas ouvrir avant d'avoir répondu.** |
| [reponses.md](reponses.md) | Votre feuille de réponses (à remplir). |

## Mode d'emploi

1. Ouvrez `questions.md` et `reponses.md` côte à côte.
2. Répondez de mémoire, avec vos mots. Une réponse approximative est utile: elle montre ce qui manque.
3. Ne relisez le code qu'après avoir écrit une première réponse.
4. Comparez avec `corrige.md` et notez-vous: ✅ solide, 🟡 partiel, ❌ à revoir.
5. Pour une correction par Claude, envoyez le contenu de `reponses.md` dans une conversation.
6. Refaites les questions notées ❌ ou 🟡 une semaine plus tard.

## Barème

| Niveau | Thème | Questions |
| --- | --- | --- |
| 1 | Syntaxe TypeScript / outils | Q1 à Q3 |
| 2 | Logique métier et dates | Q4 à Q7 |
| 3 | Algorithmes et SQL | Q8 à Q11 |
| 4 | Architecture et réactivité | Q12 à Q14 |
| Bonus | Sécurité | Q15 |

Un niveau est acquis à partir de 80 % de ✅.
